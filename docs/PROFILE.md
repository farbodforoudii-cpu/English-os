# زبان من — English OS: پروفایل یادگیری فربد (نسخهٔ ۱)

تاریخ: ۱۴۰۵/۰۸/۲۵ · منبع: مصاحبهٔ Discovery (۱۱ سؤال) + docs/ECOSYSTEM.md حساب من

## الگوی فنی (مثل حساب من و زندگی من)
- PWA، جاوااسکریپت خالص، بدون CDN؛ فونت Vazirmatn/Estedad داخل مخزن؛ ظاهر شیشه‌ای + تیره؛ آیفون و آیپد.
- داده روی دستگاه (IndexedDB `english-os`)؛ همگام‌سازی اختیاری با همان Supabase و همان کد ۲۵ نویسه‌ای (`eco_items`, app = `lang`).
- میزبانی GitHub Pages؛ `VERSION` در `sw.js` با هر انتشار؛ تست `node --test`؛ عکس قبل از تغییر ظاهری؛ انتشار فقط با تأیید.

## پروفایل
| موضوع | پاسخ | اثر روی محصول |
|---|---|---|
| بودجهٔ AI | فقط رایگان | STT/TTS داخلی آیفون (Web Speech API)؛ LLM رایگان (Gemini/Groq) از راه Supabase Edge Function؛ نمرهٔ دقیق تلفظ در MVP نیست |
| سطح صحبت | B1 (خوداظهاری) | AI آرام و کوتاه؛ کمک کلمه وسط مکالمه؛ ارزیابی صوتی اولیه برای تأیید سطح |
| حوزه‌ها | همه هم‌وزن: روزمره، تجارت، ورزش/توانبخشی، تکنولوژی/AI، (+ مالی، جواهر) | موتور پیشنهاد بر اساس فاصله از آخرین تمرین + اشتباه‌ها؛ روزمره پایهٔ همه |
| زمان روزانه | متغیر | سه دکمهٔ ۵/۱۵/۳۰ دقیقه، آخرین انتخاب پیش‌فرض |
| اصلاح | ضمنی وسط (recast)، کامل آخر | ۲–۳ اشتباه اصلی بعد از جلسه → کارت مرور (FSRS) |
| زبان توضیح | انگلیسی ساده، فارسی با یک لمس | هر کارت دکمهٔ «فارسی» |
| دلیل رها کردن قبلی | مسیر با سبک خودم جور نبود | بخش «سبک من» (قاعده‌های شخصی برای AI) + بازخورد یک‌لمسی بعد از هر جلسه |
| نوع جلسه | نقش‌آفرینی واقعی، شنیدن→صحبت، انتخاب با اپ | بحث چالشی پیش‌فرض نیست، ولی شخصیت‌ها در نقش واقعی مخالفت می‌کنند |
| محیط | هم آرام، هم شلوغ | حالت صوتی + حالت بی‌صدا (مرور، شنیدن) |
| رویکرد | Lean | تحقیق متمرکز → سند تصمیم → تأیید → MVP → استفادهٔ واقعی → بهبود |

## سؤال‌های باز (بعد از MVP)
